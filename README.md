# NEXORA CTRL NUSANTARA
**Company Profile & Landing Page: Digital Agency • Website Development • Property Management System**

> "Digital Solution for a Better Future"

Website landing page resmi dan dokumen presentasi penawaran kerja sama **NEXORA CTRL NUSANTARA**. Dirancang khusus untuk pengembang perumahan dan bisnis modern dengan integrasi media sosial, website resmi interaktif, formulir minat online, dan dashboard CRM pengelolaan calon konsumen terpusat.

---

## 🚀 Fitur Utama
- **Light & Dark Mode**: Beralih tema secara mulus dengan tombol toggle instan.
- **Tabler Icons**: Terintegrasi menggunakan CDN resmi [Tabler Icons](https://tabler.io/icons).
- **Interactive CRM Dashboard Preview**: Simulasi real-time dashboard CRM internal (*Samanea Hill Reference*) dengan status badge dan pencarian data.
- **Interactive Consumer Property Portal**: Mockup website calon pembeli dengan showcase tipe unit (36, 45, 60).
- **Simulasi Cicilan KPR**: Kalkulator interaktif estimasi angsuran per bulan dengan slider harga, DP, tenor, dan suku bunga.
- **8 Tahap Alur Sistem Pengajuan**: Navigasi tahapan interaktif registrasi calon konsumen.
- **Formulir Konsultasi**: Menghasilkan ID Registrasi unik (`REG-NXR-xxxx`) otomatis dan terhubung ke WhatsApp resmi.

## 🌐 Deploy ke Vercel
Website ini statis murni (Zero-Config) dan siap di-deploy secara instan di [Vercel](https://vercel.com):
1. Login ke [Vercel](https://vercel.com) menggunakan akun GitHub.
2. Klik **Add New Project** > pilih repository `nexora-ctrl-nusantara`.
3. Klik **Deploy**.
